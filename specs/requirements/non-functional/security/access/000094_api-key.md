# Every API route needs the API key

Every route below `/api/` must need the key of the environment variable `API_KEY` in the header
`X-API-Key`. A missing or wrong key must give 403.

Test: `tests/test_api.py:test_auth_missing_key`, `tests/test_api.py:test_auth_invalid_key`.
