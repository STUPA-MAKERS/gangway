# Repository texts are written in STE English

Docstrings, code comments, `README.md`, `AGENTS.md`, commit messages and pull request texts must
follow the rules of ASD-STE100 in S/specs/content/000022.

Reason: One simple style makes the texts easy to read, also for readers with a different first
language.
