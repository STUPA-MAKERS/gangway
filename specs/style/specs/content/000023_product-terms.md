# Product terms stay as the UI and the config show them

A spec must use the term that the UI, the API or `config.yaml` shows, for example `preset`,
`strip`, `schedule` or `target_weight`. An animation must have the name of its registry key,
for example `northern_lights`.

Reason: The reader must find the term in the application, the API or the config file.
